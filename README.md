# Flappy Bird ML Agent

A machine learning implementation of the classic Flappy Bird game using Unity, with intelligent agents trained to play the game autonomously.

## Overview

This project combines the iconic Flappy Bird game mechanics with machine learning techniques to create AI agents capable of learning to play and master the game. Built with Unity for game development and Python for machine learning workflows.

## Features

- 🎮 **Classic Flappy Bird Gameplay** - Faithful recreation of the original game mechanics
- 🤖 **ML Agent Training** - Intelligent agents trained using reinforcement learning
- 🔧 **Python Integration** - ML model training and analysis scripts
- 📊 **Performance Metrics** - Track agent learning progress and game statistics
- ⚙️ **Customizable Parameters** - Tune difficulty, training settings, and agent behavior

## Tech Stack

- **Game Development**: Unity
- **Machine Learning**: Python
- **Backend Logic**: C++, C
- **Specialized Computing**: CUDA (GPU acceleration)
- **Data Processing**: Additional languages for specialized tasks

## Getting Started

### Prerequisites

- Unity (compatible version)
- Python 3.7+
- Required Python packages (see `requirements.txt`)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Dreem-R/Flappy-Bird--ML-Agent.git
   cd Flappy-Bird--ML-Agent
   ```

2. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the Unity project in Unity Editor
